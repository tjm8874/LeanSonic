# More accurate lookup values under the original public IQ3_XXS size

We kept the 217 restored experts fixed and used the saved embedding bytes to retain more original BF16 values. A weight-only search measured the actual encoded stream lengths. The final package is **11,663,198,358 bytes**, 111,146 below the original public IQ3_XXS GGUF. The new input embedding matches 173,733,613 of 463,159,296 values exactly, versus 107,927,968 in the previous fit. Relative RMS error falls from 0.00539604 to 0.00451878 and maximum absolute weight error from 0.00830078125 to 0.0078125. This measures the input weights; corpus scorers determine the effect on predictions.

A whole group of equal absolute errors at 0.0078125 would push the embedding over budget. Higher-error values always use exact literals. At exactly that error, rows with (73 × row + 19) modulo 128 below 50 also use exact literals. This fixed rule distributes restorations through the vocabulary. At 50 classes the physical frame occupies 502,761,672 bytes; 51 classes used 503,373,440 bytes and exceeded the reserved budget. All 998 other tensor payloads and the tokenizer were checked. Sources and distribution SHA-256 values are in [receipt.json](receipt.json); the independent, full BF16 comparison is in [verified.json](verified.json).
