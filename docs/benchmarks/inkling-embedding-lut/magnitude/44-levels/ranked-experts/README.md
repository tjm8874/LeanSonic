# Reallocate the smaller 44-magnitude embedding to 354 more experts

At the same 11,663,309,504-byte IQ3_XXS limit, using the smaller input embedding allowed 571 higher-precision experts across 36 projections. The 217-expert and 571-expert packages use the same 259,021,360-byte input embedding. Package bytes including tokenizer are 11,419,458,046 and 11,662,590,054. The larger candidate is 719,450 bytes below native IQ3_XXS. The independent decoder checked all 9,342,812,160 reconstructed expert-weight bytes and 1,167,851,520 scale codes across the changed projections, then package assembly verified the 998 retained tensor payloads. Full-network BF16 tests remain pending.

Use the training ranking, low and high source packages and mixing tool from the [68-expert experiment](https://github.com/tjm8874/LeanSonic/tree/aaceb42/docs/benchmarks/inkling-codebooks/nvfp4-budget/recovered/variable-palette/global-experts). Run that experiment's assemble.py and verify.py at the revised cap.
