# Control for fitted scale thresholds

On the 571-expert class-specific package we also fitted two thresholds per projection using the sampled marginal byte entropy of retained experts. We sampled every 31st scale group, with a deterministic phase per expert. One trial uses absolute scale codes, the other offsets from the first retained-expert threshold. The real four-bank encoder measured the full frame in both cases. Relative thresholds would add a total of 7,820,752 bytes, absolute thresholds 15,630,216 bytes. Neither trial produced a smaller frame for any of the 36 projections, so the original package was retained. To reproduce, use the [parent instructions](../README.md), substitute this [banks.rs](banks.rs) and supply the class-specific package as input. [Full trial sizes](fit.json).
