# Allocate the input-embedding savings to 149 more experts

With the same 480 MiB capped input embedding, the rank fitted before any corpus evaluation supports a 217-expert prefix across 32 planes, versus 68 with the lossless input embedding. The complete model plus tokenizer occupies **11,662,534,370 bytes**, 775,134 below the 11,663,309,504-byte public IQ3_XXS GGUF. Its training-weighted expert error objective is 299,899.453. The earlier 68-expert prefix scored 334,273.447 on the same training weights. This objective excludes the input embedding. The paired full-model BF16 corpus result is still needed.

Start with the [frozen rank, sources and parent files](https://github.com/tjm8874/LeanSonic/tree/22ef9e3/docs/benchmarks/inkling-codebooks/nvfp4-budget/recovered/variable-palette/global-experts). Create an intermediate rank.json by loading that JSON, adding 116,493,516 to cap, and serializing with Python json.dumps using separators=(',', ':') and one trailing newline. The expert order and training observations stay fixed. The extra allowance is exactly the measured package size saving from [the isolated embedding change](../). Use the global-experts assemble.py to produce the full-embedding intermediate, then verify.py against the two direct-frame source packages. Finally run the embedding assemble.py on the intermediate with the same bounded.lut file as the isolated experiment. Verify the SHA-256 of both distributed files against receipt.json.

The independent expert decoder checked 8,323,596,288 weight bytes and 1,040,449,536 scale codes in affected planes. The final assembly checked all 998 payloads other than the embedding. The 217 restored expert IDs, exact prefix costs and training objective are in [expert.json](expert.json), the decode checks are in [experts-verified.json](experts-verified.json), and the final files are in [receipt.json](receipt.json).
